# 恋听网 · MyGo Music 插件

恋听网（<https://ting55.com/>，听55）的有声小说插件，版本 `1.0.0`。

## 功能

- 首页：精品、最新、全本，以及玄幻、都市、言情、穿越、惊悚、历史等栏目
- 推荐、分类、收听排行榜，支持翻页
- 书籍详情：作者、播音员、简介、全部章节
- 播音员页：该播音员的作品
- 搜索：按书名搜索
- 喜欢、播放历史
- 章节音频播放

## 数据映射

站点没有“歌曲”概念，因此：

- **一本书 = 专辑**
- **一集 = 曲目**，ID 形如 `14918-1`，代表第 14918 本书第 1 集
- **播音员 = 歌手/Artist**

书籍页会一次列出全部集数，所以专辑页能直接得到完整章节列表；章节标题只有在单集页面才存在，列表里显示为“第 N 集”。

## 播放实现

章节页并不内嵌 MP3。插件读取章节页的 `_c`、`_b`、`_cp`、`_p` 等 meta，携带 `xt` 和 `l: 1` 请求 `POST /nlinka`，由站点返回 `pp.ting55.com` 上的 MP3 地址；如果桌面接口失败，会再走移动版 `m.ting55.com/glink` 兜底。

音频请求带 `Referer: https://ting55.com/book/<书>-<集>`。返回的地址带时效性，每次播放都会重新获取。

站点没有歌词，`lyrics` 返回空对象。

## 已知限制

- 章节列表只显示序号，不逐集抓取标题。
- 搜索没有分页，返回站点搜索结果首页。
- 音频由 `pp.ting55.com` 提供，若该 CDN 在当前网络不可达，播放会失败；插件会尝试移动版接口重新取链。
