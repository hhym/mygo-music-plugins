# 米粒音乐 · MyGo Music 插件

米粒音乐网（<http://www.milimusic.cn/>）的 MyGo Music / 千千静歌插件，版本 `1.0.0`。

## 功能

- 首页：每日推荐、最新专辑
- 分类：流行金曲、港台新歌、日韩新歌、怀旧经典、DJ 歌曲、欧美新歌，支持翻页
- 最新专辑与歌手库，专辑详情、歌手详情
- 搜索：歌曲、专辑、歌手
- 喜欢、播放历史
- 歌词

## 安装

把 `milimusic-plugin` 整个文件夹放进 MyGo Music 的插件目录，或在应用内选择本目录的 `plugin.json` 安装。插件无需构建，入口为 `index.js`。

## 实现说明

站点页面使用 **GB2312/GBK** 编码，而 MyGo 运行时的 `TextDecoder` 只支持 UTF-8。插件内置了一张 GBK 双字节映射表，直接读取 `ArrayBuffer` 解码，因此中文歌名、歌手和分类不会乱码；搜索关键词也会先编码为 GBK 再提交。

站点当前只提供 Flash 播放器和返回空内容的 `player.php`，页面与下载页都没有可直接访问的 MP3 地址。插件按“歌名 + 歌手”在网易云匹配同一首歌，使用网易云外链 MP3 播放并获取歌词；匹配不到的歌曲会返回 `unavailable`，不会伪造音频地址。

站点边缘节点偶发 502/503，插件对页面请求做了 4 次退避重试和 3 分钟页面缓存。

## 已知限制

- 音频与歌词依赖网易云同名匹配，站点本身没有可播放音频。
- 歌手页只展示站点提供的歌曲，部分歌手可能没有完整曲库。
- 专辑库、歌手库首页没有翻页链接，插件只展示首页条目。
