# 番茄音乐 · MyGo Music 插件

番茄音乐（<https://www.novelfm.com/>，原番茄畅听音乐版）的网页版插件，版本 `1.0.0`。

## 功能

- 首页：热门歌曲（约 200 首），按站内热度排序
- 排行榜：同一批热门歌曲的完整列表
- 搜索：按歌名、歌手、专辑在首页索引里匹配（站点网页版没有搜索接口）
- 歌曲详情、歌手页（同名歌手聚合）、专辑页（单曲专辑）
- 歌词：把页面里的逐字时间轴转成标准 LRC
- 播放：取歌曲页 SSR 数据里的 `video_info.main_url`，m4a 直链，Range 探测文件大小用于显示时长

## 实现说明

- 页面是 Next/Modern.js SSR，数据在 `window._ROUTER_DATA` 的 `loaderData["music_(id)/page"].pageData`
- 音频域名 `*.novelfmvod.com`，不需要 Cookie，请求带 `Referer: https://www.novelfm.com/`
- 封面来自 `*.byteimg.com`，链接里带签名参数，过期后由页面实时取新链接

## 已知限制

- 网页版只有「热门歌曲」一个栏目，没有搜索、榜单、分类接口，搜索结果是首页 200 首的本地匹配，搜不到长尾歌曲
- 专辑页只能展示当前这一首（页面不提供整张专辑的曲目列表）
- 歌手页只能聚合首页索引里出现过的歌曲
