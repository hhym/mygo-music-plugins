# 无名音乐 · MyGo Music 插件

把 [无名音乐网](https://www.mvmp3.com/)（mvmp3.com）接进 [MyGo Music](https://github.com/egoist/mygo-music)：榜单、歌单、歌手、专辑、搜索，在线试听 MP3 并显示 LRC 歌词。

插件只有一个 `plugin.json` 和一个 `index.js`，无需构建，macOS / Windows / Linux 通用。

## 安装

1. 打开 MyGo Music → 设置 → 插件 → `+` → Show Plugins Folder。
2. 把 `mvmp3-plugin` 文件夹放进该目录（或把 `mvmp3-plugin.zip` 解压进去），重启应用。
3. 在 设置 → 插件 里启用“无名音乐”。

## 功能

- **首页**：推荐音乐（每日更新）、他们在听、热门歌单、推荐歌手。
- **排行榜**：TOP、欧美、内地、恋爱的歌，可翻页。
- **歌单**：按主题分类（国语经典、睡前推荐、纯音精选、年代歌单等），可进入歌单详情播放整张列表。
- **歌手 / 专辑**：歌手最新歌曲与专辑列表，专辑页列出全部曲目。
- **搜索**：按歌名或“歌手 + 歌名”搜索，每页 30 首，可继续加载。
- **歌词**：读取站点播放接口返回的 LRC，并去掉站点加在开头的水印行。
- **我的喜欢 / 收藏专辑 / 最近播放**：站点没有账号体系，这三项由插件本地保存。

## 站点的人机验证

站点给网页加了一道“我不是人机”的勾选验证，验证状态和会话 Cookie 绑定。插件会自动处理：

1. 请求页面时如果拿到验证页，取出其中的 `csrf_token`；
2. 向同一地址提交 `csrf_token` 与 `human_check`；
3. 带着返回的 `PHPSESSID`、`server_name_session` 重新请求。

插件自己的 `fetch` 不会保存 Cookie，所以 Cookie 由插件记录（保存在插件存储里），并在每次请求时手动带上。站点声称验证状态保持 1 小时；实测同一会话可连续访问多页，个别新页面会再次要求验证，插件会再走一遍上面的流程。

如果验证反复失败（例如站点换了验证方式），可以在插件设置里粘贴浏览器 Cookie 兜底：浏览器打开 www.mvmp3.com 通过验证 → 开发者工具 Network 里复制任意请求的 `Cookie` 请求头 → 粘贴到“会话 Cookie（可选）”。

## 音频与歌词的来源

站点所有歌曲页都调用同一个接口：

```
POST https://www.mvmp3.com/style/js/play.php
id=<歌曲 hash>&type=dance
```

返回 JSON：`title`、`name`、`singer`、`pic`（封面）、`url`（MP3 直链）、`lrc`（歌词）。插件按 `dance` → `mp3` → `music` → `song` 的顺序尝试，取第一个带 `url` 的响应。直链带时效，插件在用户点播时才去取，所以不会过期。

## 已知限制

- 站点没有账号，因此没有登录、云同步、评论；“喜欢 / 收藏 / 历史”只存在本机插件存储里。
- 站点导航里的“日本歌曲 / 韩国歌曲”分类页本身已失效（直接返回“您的操作有误”），插件不收录这两个榜单。
- 搜索只支持歌曲（站点本身不提供专辑、歌手搜索）。
- 歌单页、部分榜单页不标歌曲时长，这些曲目显示 00:00；搜索页与榜单页有时长。
- 歌单详情页的分页参数在站点上偶尔返回与第一页相同的内容，插件会去重。
- 站点内容版权归原权利人所有，插件只做页面解析和跳转播放，不下载、不转存。

## 发布到插件目录

1. 新建公开 GitHub 仓库，把 `plugin.json`、`index.js`、`locales/` 放在仓库根目录。
2. 给仓库加 topic `mygo-music-plugin`，就会出现在 [插件页](https://mygo-music.egoist.dev/plugins)。
3. 安装按钮链接：`mygo-music://install-plugin?repo=<owner>/<repo>`。
