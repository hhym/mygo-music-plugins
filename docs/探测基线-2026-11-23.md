# 探测基线（2026-11-23）

用 `node scripts/probe.mjs` 在一台**国内** Linux 云主机上跑出来的第一次全量基线。以后每次跑完和这张表对比，就能看出哪个站改版了。

方法：每个插件独立进程加载 → `home()` 取第一首（首页只有专辑时顺着第一个专辑取一首）→ `stream()` 拿地址 → 对地址发一个 1 KB 的 `Range` 请求，看状态码和 MIME。

判读：`206/200` 算可播；`403/503` 是出口被站点拒绝，不一定是插件问题；`stream 报错` 要看报什么，兜底源（蜻蜓、网易云匹配）失败和插件逻辑错误要分开看。

## 逐条解读

| 结论 | 插件 | 说明 |
| --- | --- | --- |
| 可播 | 36DJ舞曲、世纪音乐、5sing、布谷音乐、汽车音乐网、DJ024电音、凤梨音乐、好听轻音乐、275听书、一起听歌吧、米粒音乐、猫耳FM、九天音乐、听听网、VY音乐 | 地址回 206，MIME 正确，能出声 |
| 设计如此 | 5nd音乐 | 音频域名只认浏览器，插件主动跳浏览器，不是故障 |
| 兜底源失败 | 飞卢听书、单田芳评书网、听FM电台、悦听吧 | 源站地址没解析到，回退蜻蜓 FM 也没找到同名音频；插件逻辑没问题，是兜底链断了 |
| 站点侧无地址 | GD音乐台、米乐迪音乐、无名音乐、优折美音乐 | `stream()` 走到「这首歌没有可用地址」，多半是站点接口当天没给流或换了签名 |
| 首页无可播项 | 动感酷音乐、小蜜蜂音乐、听书网 | 首页没有直接曲目，专辑接口当天 503 / 超时（听书网明确回了 503） |
| 出口被拒 | 恋听网 | `pp.ting55.com` 对云主机出口回 503，换网络即正常 |
| 站点不可达 | 闪闪音乐 | 首页 `fetch failed`，33ve 当天连不上 |

米粒音乐 39 秒、动感酷音乐 22 秒，是站点本身慢（首页串行抓多个页面），不是插件卡死。

## 怎么用

```bash
node scripts/probe.mjs              # 全量，出表
node scripts/probe.mjs 36dj-music   # 只探一个
node scripts/probe.mjs --json       # 机器可读，存两份做 diff
```

下一轮基线出来时，按 id 对一遍表就能定位「谁从可播掉成了报错」。
